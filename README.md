# AETHERIA: AI 비전 & QR 보스 레이드 (Prototype)

실물 카드를 카메라로 비추면 **AI 비전 에이전트**가 카드를 직접 읽고 스킬을 발동하며, 실시간 반응형 보스와 겨루는 하이브리드 보스 레이드 웹앱입니다. (QR 스캔 및 가상 덱 시뮬레이터도 함께 지원합니다.)

## 주요 기능

- **AI 비전 카드 에이전트 & 도감 (`발견한 AI 도감`)**:
  - **비전 데모 모드**: API Key 없이 즉시 카드 색상·장면을 실시간 분석해 플레이 가능.
  - **로컬 AI 모드**: 자체 실행 중인 로컬 비전 서버(OpenAI 호환 `/v1/chat/completions` 또는 Ollama `/api/chat`) 연결.
  - **웹 API Key 모드**: 웹 배포 환경에서 Gemini (`gemini-2.5-flash`) 또는 OpenAI (`gpt-4o-mini`) API Key 입력 지원 (`localStorage` 로컬 보관).
  - **손을 떼고 자동 인식 (`자동 인식`)**, **사진 업로드**, **4종 샘플 비전 카드**, 및 **발견한 AI 도감** 재발동 지원.
- **오리지널 레이드 전투 시스템**:
  - **3종의 반응형 AI 보스**: 바인글로리 코어 · 칼로스 프라임 · 크로노스 웜 (각 보스별 Phase 2 각성 & 고유 기믹).
  - **원소 반응 & 잔류 공명 필드**: `과부하 융해`(R+B), `시간 균열`(B+G), `파쇄 치명타`(R+G) 및 1턴 잔류 공명 버프.
  - **3장 체인 피니시 & 보스 그로기**: 메인+부스트 2장 완성 시 트리플 공명 피니시, 3보호막 파쇄 또는 2반응 시 보스 그로기(반격 무효).
  - **전술 유물 4종 · 3단계 난이도(표준/영웅/심연) · 3연전 건틀릿 모드 · S~C 등급 레이드 도감**.
  - **실시간 전술 힌트(`getTacticalHint`) · Phase 2 각성선 표시 · 원소 반응 조합표**.
- **2D 액션 보스 뷰포트 (PixiJS v8) & Web Audio SFX**: 생성형 보스/아레나 아트, 속성별 참격/광선, 파티클 버스트, 화면 흔들림, 4개 주사위 굴림 연출.
