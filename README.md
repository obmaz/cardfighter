# 킨파이어 델브: AI 비전 & QR 보스 레이드 (Prototype)

실물 카드를 카메라로 인식해 보스를 공략하는 하이브리드 보스 레이드 웹앱 프로토타입입니다. **AI 비전 에이전트**가 카드를 직접 보고 능력치를 해석해 공격하거나, QR 코드·가상 시뮬레이터로 즉시 플레이할 수 있습니다.

## 주요 기능

- **AI 비전 카드 에이전트**:
  - **로컬 AI 모드**: 자체 실행 중인 로컬 비전 서버(OpenAI 호환 `/v1/chat/completions` 또는 Ollama `/api/chat`)에 연결해 API Key 없이 실행.
  - **웹 API Key 모드**: 웹 배포 환경에서 사용자가 직접 Gemini (`gemini-2.5-flash`) 또는 OpenAI (`gpt-4o-mini`) API Key를 입력해 사용 (`localStorage` 로컬 보관).
  - 카메라 실시간 캡처(`AI 카드 인식`) 및 이미지 파일 업로드(`사진`) 모두 지원.
- **QR · 비전 하이브리드 스캐너**: 브라우저 전면 카메라(`BarcodeDetector` + `jsQR` ROI 폴백) 및 실시간 프레임 차분 모션 감지.
- **2D 액션 보스 뷰포트 (PixiJS v8)**: 속성별 참격/충격파/랜턴 광선, 보호막 파쇄, 파티클 버스트, 화면 흔들림, 플로팅 데미지 및 4개 주사위 자동 굴림.
- **2종의 반응형 AI 보스**:
  - **바인글로리 코어 (50 HP)**: 3색 보호막, 단일 속성 편중 시 과열 반격, 3색 균형 시 `[불안정]`(피해 +50%), 체력 25 이하 `[우물의 심연]` 방해 챌린지.
  - **칼로스 프라임 (45 HP)**: `[무적 보호막]`, 파랑 플라스크 파쇄 시 킨파이어 랜턴 충전, 탈진 시 공허 게이지 누적.
- **테스트 카드 덱 & QR 코드 생성기**: 3명의 탐구자(코르·아샤·롤랜드 각 18장 + 공유 랜턴 2장) 가상 스캔 및 화면 QR 코드 출력 지원.
